## Stage 4 实现完成（3.3.3 应收逾期预警助手）

- **口径修正**：expected_overdue_days = max(0, expected_payment_date − due_date)（相对到期日，非当前日期）；expected_payment_date = 最早到期未结应收的 due_date + 历史平均正向回款延迟（无历史付款为 0）；requirements/api/architecture 同步（含修订注记）。
- **scoring_engine**（domain/scoring_engine，纯确定性无 LLM）：aging 单笔分档 0/30/50/70/90（未逾期/1-30/31-90/91-180/>180）按未结余额加权；term = clamp((120−term)/120×100, 0, 100)（term_cap 默认 120）；payment = overdue_rate(逾期结清/结清×100)×0.5 + delay(min(平均正向延迟/90,1)×100)×0.5（无历史结清=0）；collection = 无催收 0 / 最近催收后回款 0 / 其后无回款且有未结 100；总分 = aging×0.4+term×0.2+payment×0.3+collection×0.1 ROUND_HALF_UP；<40 low / 40-69 medium / ≥70 high；无未结 → 0/low。
- **factors 契约**：每因子 {raw_score, weight, weighted_score, detail}（detail 含计算依据）。
- **模型**：ArRiskScore + score_date + overdue_amount + unique(customer_id, score_date)（同日 upsert 幂等）；新增 ar_risk_run 表（周期任务状态）；0003 条件化迁移。
